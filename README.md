# Social Media Analytics SQL Project

## About the Project

This project analyzes social media data using SQL to generate insights
about users, posts, comments, likes, followers, and hashtags.

The analysis focuses on user activity, post engagement, content
performance, and follower-related insights.

## Database Tables

- Users
- Posts
- Comments
- Likes
- Followers
- Hashtags
- Post_Hashtags

## SQL Concepts Used

- SELECT
- WHERE
- JOIN
- GROUP BY
- HAVING
- Aggregate Functions
- Subqueries
- CTEs
- CASE Statements
- EXISTS
- NOT EXISTS
- COALESCE
- Ranking

## Analysis Performed

- Identified active users
- Analyzed most-liked posts
- Analyzed user engagement
- Identified popular hashtags
- Compared engagement across countries
- Analyzed followers and content performance

## Tools Used

- MySQL
- SQL
